# 🏇 탭 더비 (Tap Derby)

팀원들이 스마트폰 화면을 두드리면 우리 팀 경주말이 달리는 **워크숍용 팀 대항 게임**입니다.
로그인 없음 · QR코드 접속 · 서버 설치 없음 (GitHub Pages 정적 호스팅 + WebRTC).

## 사용 방법
1. 노트북에서 `https://<내계정>.github.io/<저장소>/host.html` 열기 (프로젝터/큰 화면 연결, F11 또는 "전체화면" 버튼)
2. 팀 수 · 팀 이름 · 경주 길이 선택 → **참가자 모집 시작**
3. 참가자들이 QR코드를 스캔 → 닉네임(선택) 입력 → 팀 선택
4. **출발!** → 3·2·1 카운트다운 → 폰 화면을 연타!
5. 결과 화면에서 "같은 팀으로 다시!" 로 바로 다음 판 진행

## GitHub Pages 배포
1. GitHub에서 새 저장소 생성 (Public)
2. 이 폴더의 파일을 모두 push
3. Settings → Pages → Branch: `main` / `(root)` → Save
4. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 접속

## 공정성 규칙
- 진행률 = 팀 총 탭 수 ÷ 출발 시점 팀 인원 ÷ 목표 탭 수 → **팀 인원이 달라도 공정**
- 1인당 초당 최대 12탭까지만 인정 (매크로/기계적 연타 방지)
- 출발 후에는 신규 입장 불가 (끊긴 사람의 재접속은 가능)

## 구조
- 진행자 화면(`host.html`)이 "서버" 역할, 폰(`play.html`)이 PeerJS(WebRTC)로 직접 연결
- 접속 중계(시그널링)만 PeerJS 무료 공개 서버 사용, 게임 데이터는 기기끼리 직접 전송
- `vendor/` 에 PeerJS, QR 라이브러리 포함 (CDN 불필요)

## 알아둘 점
- **행사장 와이파이가 기기 간 통신을 막는 경우(AP 격리)**, 폰은 LTE/5G로 접속하면 대부분 해결돼요. 진행자 노트북은 인터넷만 되면 됩니다.
- 무료 공개 PeerJS 서버를 쓰므로 아주 드물게 접속이 느릴 수 있어요. 워크숍 전 한 번 리허설을 권장합니다.
- 노트북 화면이 꺼지거나 진행자 탭을 닫으면 게임이 끊겨요 (절전 모드 해제).
- 참가자 수 권장: 총 60~80명 이하.

## 직접 PeerJS 서버를 쓰고 싶다면
`npx peer --port 9000 --path /` 실행 후 `host.html?peer=서버주소:9000` 으로 접속하면 QR에도 자동 반영됩니다.
